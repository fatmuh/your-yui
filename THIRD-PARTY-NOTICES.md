## Workbox service worker runtime (installed by epic-pwa, exact pin)

The production build (`npm run build`) emits a generated service worker that
bundles the Workbox runtime into the served artifacts `dist/sw.js` and
`dist/workbox-*.js`. The code is generated by `vite-plugin-pwa` 2.0.0 (MIT,
Copyright Anthony Fu) from the `workbox-*` packages below, all MIT
(Copyright 2018 Google LLC); the minified bundle carries no license banner,
so attribution lives here:

| Bundled package | Version | License |
| --- | --- | --- |
| `workbox-precaching` | 7.4.1 | MIT |
| `workbox-routing` | 7.4.1 | MIT |
| `workbox-strategies` | 7.4.1 | MIT |
| `workbox-navigation-preload` | 7.4.1 | MIT |
| `workbox-core` | 7.4.1 | MIT |

`vite-plugin-pwa` itself is a build-time devDependency and is not bundled
into any served artifact. The list above is updated when the pinned versions
change.
